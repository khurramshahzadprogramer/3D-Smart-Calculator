# 🧮✨ KHURRAM CALCULATOR PRO

### 💎 Premium Browser Calculator · V3.0

> A modern, responsive and feature-rich calculator built with **HTML,
> CSS & JavaScript** --- combining powerful calculations with a polished
> glassmorphism interface.

  ⚡ Feature               ✨ Details

## 💾 Local Storage

The project uses the browser's **localStorage** to persist supported
user preferences.

Stored experience can include:

-   🎨 Theme settings
-   ⚙️ Calculator preferences
-   🕘 Calculation history
-   🔊 Audio preferences
-   🖥️ Display customization

No external database is required.
